## 2024-06-16 - Add missing ARIA labels to Compare Tools Grid toggle buttons
**Learning:** Buttons that display an item name and an 'X' icon for removal can be read improperly by screen readers if they lack an explicit `aria-label`. Without an `aria-label`, the screen reader might just read the item name (and potentially the "X" symbol), not conveying the actual *action* that clicking the button will perform (which is to remove the item from the comparison).
**Action:** When creating buttons that serve to remove a selected item (often seen as tags with a "close" icon), always explicitly add an `aria-label` like `Remove ${itemName}` (in this context, keeping consistent with English for aria labels based on previous memory constraints) so the action is clear to users relying on assistive technologies.
