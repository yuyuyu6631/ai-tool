## 2025-03-01 - 搜索输入框性能优化
**经验：** 在处理带有实时 NLU 解析和模糊搜索（Fuse.js）的高频输入场景（如 CommandPalette）时，如果每次击键都同步计算解析意图并更新渲染 DOM，会阻塞主线程导致输入卡顿。虽然可以实现自定义防抖逻辑，但 React 的 `useDeferredValue` 提供了一种更优雅的方式，它允许 React 优先处理用户输入，在后台并发渲染昂贵的计算和 UI 更新。
**行动：** 在 React 18+ 环境中，优先使用 `useDeferredValue` 优化这类涉及本地昂贵计算（如 Fuse.js）的高频搜索输入场景。
