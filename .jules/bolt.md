
## 2025-02-24 - 优化全局搜索组件性能
**经验：** 在处理高频用户输入（如搜索框）且涉及昂贵的本地计算（如 fuse.js 模糊搜索和 NLU 解析）时，同步更新状态会导致主线程阻塞，造成输入卡顿。
**行动：** 使用 React 18+ 的 `useDeferredValue` 来延迟搜索关键字的状态更新，并将衍生计算（fuse 搜索）包裹在 `useMemo` 中。这能在不阻塞 UI 渲染的情况下处理繁重的查询，替代了传统的自定义 debounce 逻辑。注意，使用 `useDeferredValue` 必须结合 `useMemo` 才能真正避免急迫渲染时的重复计算。
