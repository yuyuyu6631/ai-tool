## 2025-07-06 - 优化 Command Palette 搜索性能
**经验：** `CommandPalette` 组件在用户输入任务描述或分类关键词时会触发 NLU 意图解析 (`parseSearchIntent`)，该过程涉及大量的字符串正则表达式替换及匹配，是相对昂贵的计算操作。之前每次键入都会同步触发该计算，可能在低性能设备或快速输入时引发卡顿。
**行动：** 在处理高频触发且涉及同步计算（尤其是模糊搜索和复杂文本解析）的输入时，使用 `useDeferredValue` 是一种低侵入、高收益的优化方式。它不影响代码可读性，还能借助 React 的并发特性（Concurrent Features）优先保证用户输入的流畅性。下次遇到依赖即时输入的计算任务，优先考虑 `useDeferredValue` 替代防抖（如果计算本身是同步的，防抖仍会阻塞主线程渲染那一下，而 deferred value 能中断和重用渲染）。
