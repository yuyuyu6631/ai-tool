## 2025-02-18 - 🛡️ Sentinel: 修复通过DNS重绑定和不完整IP检查绕过SSRF的问题
**Vulnerability:** 工具解析器中的 URL 验证仅检查提供的纯文本主机名字符串是否为私有 IP 地址。如果攻击者提供一个可以解析为本地/私有 IP 的域名，或者通过 DNS 重绑定技术让域名解析返回多个 IP（其中一个是私有 IP），从而绕过了验证。
**Learning:** 依赖网络解析的安全检查在 DNS 解析失败时必须采用“安全失败”（fail closed）策略。并且必须迭代检查 `socket.getaddrinfo` 返回的所有 IP，只要有一个是内网地址就要拦截，以防止绕过。
**Prevention:** 始终使用 `socket.getaddrinfo` 主动解析主机名并迭代遍历返回的所有 IP。一旦发生 DNS 解析错误立刻拒绝请求，并拦截任何试图访问私有、回环或保留地址的行为。
