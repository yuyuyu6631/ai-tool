## 2024-05-24 - [SSRF Bypass via ValueError in ipaddress module]
**Vulnerability:** The application was vulnerable to SSRF because URL validation bypassed domain names that resolve to local/private IPs (like `localtest.me` resolving to `127.0.0.1`). The code relied solely on `ipaddress.ip_address()` which throws a `ValueError` for valid domain strings, allowing the validation to pass without checking the resolved IP.
**Learning:** Relying on `ipaddress.ip_address` to parse hostnames is insecure as it does not perform DNS resolution. Catching its `ValueError` for domains effectively allows attackers to point domains to internal network addresses, bypassing the IP address checks entirely.
**Prevention:** Always perform DNS resolution using `socket.getaddrinfo()` (or `socket.gethostbyname()`) to obtain the actual underlying IP addresses before validating them with `ipaddress.ip_address()`. Ensure that all resolved IPs for a given hostname are checked against private/reserved ranges.
