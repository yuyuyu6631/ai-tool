## 2024-05-24 - [SSRF via Localhost Aliases bypasses `ipaddress` Validation]
**Vulnerability:** The `validate_public_url` in `tool_parser_service.py` was vulnerable to Server-Side Request Forgery (SSRF). It attempted to use Python's `ipaddress.ip_address()` to validate hostnames. However, `ipaddress` only takes IP strings, so domains like `localhost`, `localtest.me` or internal company subdomains would throw a `ValueError`. The exception was caught and bypassed the private IP validation, making internal networks accessible!
**Learning:** You cannot pass a hostname to `ipaddress.ip_address()` directly. DNS resolution must occur first to find the actual IP the hostname points to, ensuring that external-looking hostnames that resolve to internal IPs (like 127.0.0.1 or 192.168.x.x) are correctly blocked.
**Prevention:** Always use `socket.gethostbyname` or `socket.getaddrinfo` to resolve the DNS hostname into an IP address *before* running it through `ipaddress.ip_address` to determine if it is a private/internal IP.
