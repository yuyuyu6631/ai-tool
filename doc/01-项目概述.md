# 项目概述

## 产品名称

- 中文名：星点评
- 英文名：Xingdianping
- 当前定位：面向互联网公司工作场景的 AI 工具使用经验社区

## 当前定位

当前仓库已经不是“只做前台展示的纯 Demo”。  
它的真实基线是一个正在持续演进的 MVP：

- 公开站点由 `apps/web` 承载
- 真实后端由 `apps/api` 承载
- 页面与数据以真实 API 和数据库模型为准
- 已包含基础认证、用户评论、后台管理入口和榜单运营能力

当前产品方向不再停留在“罗列 AI 工具”。  
星点评要回答的是：**用户围绕具体任务应该用什么 AI 工具、别人怎么用、有没有可低成本尝试的福利。**

## 核心价值

平台当前要解决的是“怎么让用户围绕真实工作任务更快找到合适 AI 工具，并通过真实经验学会怎么用好”。

核心价值不是“工具多”，而是：

- 任务清楚：优先从用户要完成的任务进入，而不是先按岗位筛选
- 用法具体：不只推荐工具，还展示相关经验、操作过程、输出效果和使用心得
- 福利可达：把免费额度、试用权益和官方体验入口集中展示，降低尝试成本
- 资产可沉淀：通过收藏、发布、浏览历史和个人中心沉淀用户自己的 AI 使用资产

围绕这个目标，当前代码已经具备四类核心能力：

1. 目录型发现：按搜索词、分类、标签、价格、访问限制筛工具
2. 决策型详情：进入单工具详情页查看描述、评分、评论摘要、同类替代
3. 场景型推荐：通过场景页、首页推荐区和比较页帮助缩小范围
4. 运营型维护：后台管理工具、评论和榜单，维持内容可更新

这些能力应继续作为基线使用，但后续要更多承载“任务场景 -> 工具 -> 经验 -> 福利 -> 收藏/发布”的闭环，而不是只做工具罗列。

## 当前用户类型

### 公开站点用户

- 想围绕具体工作任务快速找到合适 AI 工具的人
- 需要中文可用、价格可控、访问限制明确的企业办公角色
- 销售 / 售前：客户调研、会议纪要、投标材料、销售话术
- 产品 / 项目：需求分析、PRD、原型、流程图、竞品分析
- 研发：项目拆解、代码生成、Bug 修复、工程规范
- 测试：测试用例、测试脚本、测试报告、测试数据
- 运营：短视频脚本、小红书文案、海报文案、活动策划

### 后台用户

- 负责维护工具目录、榜单和评论内容的管理员
- 未来负责维护教程、经验帖、场景方案等内容资产的运营人员

上面“未来负责”属于产品方向，不代表对应后台能力当前已全部落地。

## 当前阶段目标

当前阶段的目标不是”继续证明能不能做”，而是在现有主干上验证“任务经验社区闭环”是否成立：

- 让首页和场景入口先帮助用户确认“我要完成什么任务”
- 保持目录、详情、场景、评论和后台口径一致
- 验证用户是否愿意沿着“任务场景 -> 经验帖 -> 工具详情 -> 免费福利 -> 收藏/发布”路径继续浏览
- 验证平台内容是否比用户直接问 ChatGPT、搜索或刷短视频更省事
- 让文档跟着代码自动更新，而不是继续靠手写 PRD 推动
- 补齐运营闭环（抓取审核发布）
- 推进内容深度（经验帖、福利、星启生态工具、收藏和个人中心沉淀）
