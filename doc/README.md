# 文档索引

本目录用于维护项目当前的产品说明、页面规范、接口约定、数据结构和阶段性记录。

## 最高约束

- 本项目以最终用户展示效果为最高导向，先读 [00-最终效果约束.md](./00-最终效果约束.md)
- 代码、文档、测试和架构都服务于目标展示效果，不得反过来限制合理的产品改进
- `../docs/current-implementation-baseline.md` 只描述当前实现，不代表产品上限

## 当前基线

- 当前前端基于 `Next.js 15 + React 19 + Tailwind CSS 4`
- 当前后端基于 `FastAPI + SQLAlchemy 2 + Alembic + MySQL`
- 前端已接入真实 API，默认开发接口为 `http://localhost:8000`
- 最新产品 PRD 以 [prd.md](./prd.md) 为准，定位为“面向互联网公司工作场景的 AI 工具使用经验社区”
- 当前产品主轴是“任务场景 + AI 工具库 + 经验社区 + 免费 AI 福利 + 星启生态工具入口”
- 当前公开页面包含首页、工具目录页、工具详情、场景页、对比页、匹配页、免费福利页、按任务搜索页、场景详情页、引导页和认证页
- `/rankings` 是兼容重定向入口，当前承接到首页
- `/guide` 是兼容入口，重定向到 `/tools?mode=ai`
- 首页与目录能力已经合并为”统一入口 + 双模式搜索 + 雷达推荐展示”的当前形态
- 工具详情和后台工具管理已经包含产品元素字段，前后端类型通过 `packages/contracts` 对齐
- 精选首页工具数据位于 `apps/api/app/data/homepage_curated_tools.json`，可通过 `npm run sync:home-tools` 同步到数据库
- 文档中标记为“未来规划”的内容，仅代表目标方向，不代表当前代码已实现
- `../docs/current-implementation-baseline.md` 为自动生成基线，提交前会随代码一起刷新
- 当前主仓库为 `https://github.com/yuyuyu6631/ai-tool`，本地 `main` 应跟踪 `ai-tool/main`

## 使用原则

- 以最终用户展示效果为最高导向
- 当前代码是实现事实来源，但不是产品效果上限
- 当前实现文档与未来规划文档必须分开阅读
- 若文档与代码冲突，先确认目标展示效果；当前实现问题以代码为准，产品目标问题以目标效果为准
- 若旧代码、旧文档或旧测试阻碍目标展示效果，应在可验证范围内修改它们
- 布局大改期间，优先保持 README、文档索引、页面规范三处口径一致
- 需要快速确认真实路由、API、模型和测试时，优先查看 `../docs/current-implementation-baseline.md`
- 提交文档前建议运行 `npm run docs:check`；涉及前端 UI 时同步运行 `npm run lint:web`、`npm run test:web -- --run` 和 `npm run build:web`
