# 产品范围

## 当前已实现范围

### 公开页面与承接入口

当前已落地并可访问的主要页面：

1. 首页 `/`
2. 工具目录页 `/tools`
3. 工具详情 `/tools/[slug]`
4. 场景列表 `/scenarios`
5. 场景详情 `/scenarios/[slug]`
6. 对比页 `/compare/[comparisonSlug]`
7. 匹配页 `/matches`
8. 认证页 `/auth`
9. 免费福利页 `/deals`
10. 按任务搜索页 `/search`
11. 场景详情页 `/scene/[slug]`
12. 引导页 `/guide`

当前兼容入口：

- `/rankings`：当前直接重定向到 `/`

### 公开能力

当前已经在代码中落地的能力：

1. 首页统一搜索/筛选承接
2. 首页按专家推荐优先及内容分级策略（Head/Mainstream 等）渲染
3. 视图切换（推荐 / 热门 / 最新 / 免费 / 国产）
4. 目录筛选：搜索、分类、标签、价格、访问限制、排序、分页
5. 工具详情：基础信息、评分、评论摘要、相似工具、场景推荐
6. 用户认证：注册、登录、登出、恢复登录态
7. 用户评论：查看已发布评论、查看自己的评论、提交/更新自己的评论
8. 对比页：2 到 3 个工具横向比较
9. 后台管理：总览、工具管理、评论管理、榜单管理、匹配方案管理（已集成细粒度的 RBAC 角色操作权限保护）
10. AI 搜索：`GET /api/ai-search`
11. RAG 对话：`POST /api/chat`
12. 数据导入/校验与轻量抓取入口

## 当前不在已完成范围内的内容

以下内容当前仍未形成完整闭环，或仍停留在规划阶段：

- 收藏历史与个人中心
- 支付、订单、会员体系
- 第三方 OAuth 社交登录
- 完整抓取审核发布闭环（入口已存在，审核工作流未闭环）
- SEO 专题生产系统
- 多轮聊天会话管理与历史归档
- 更完整的用户社区互动体系
- 工具厂商自助入驻

## 最新 PRD 下的 MVP 范围

以下内容来自最新 PRD V1.1，用于校准产品方向和研发优先级，不代表当前代码已经全部落地。

### P0 必须优先验证

- 首页：承接搜索、任务场景、工具、经验、福利和星启生态入口
- 任务场景页：按任务聚合相关经验帖、适用工具和免费 AI 福利
- AI 工具库：支持工具列表、搜索、筛选、官方工具标识和工具收藏入口
- 工具详情页：展示工具基础信息、适用任务、相关经验和相关福利
- 经验社区列表：支持经验内容展示，并按任务、工具、官方精选、最新/热门筛选
- 经验帖详情：展示任务背景、使用工具、操作过程、输出效果、心得和可复用要点
- 免费 AI 福利列表：展示福利、筛选福利，并引导进入福利详情
- 福利详情页：展示领取方式、有效期、使用限制、相关工具和经验
- 登录/个人中心：接入账号体系，承接收藏、发布和浏览历史入口
- 收藏功能：支持收藏工具、经验帖和福利

### P1 可后置的增强能力

- 用户发帖
- 评论
- 点赞
- 官方精选运营
- 星启生态工具入口强化
- 综合搜索结果页：聚合工具、经验、福利和任务场景结果
- 后台经验内容管理
- 后台免费福利管理

### P2 暂不优先推进

- 浏览历史深度运营
- 福利订阅提醒
- 工具热度榜
- 个性化经验内容推荐
- 复杂等级体系、积分系统和付费会员
- 工具厂商自助入驻

## 当前边界说明

- 当前项目已经不是“只有静态演示”的纯前端 Demo
- 当前项目也还不是完整商业化产品，仍处于 MVP 演进阶段
- 后台与评论已经进入当前事实，但抓取审核和商业化仍未闭环
- 岗位场景方案、教程/经验帖、提示词模板和后台内容管理是当前产品方向中的重点，其中部分能力仍属于待实现范围
- 文档中的未来能力仅作规划，不应误认为已经在代码中落地
